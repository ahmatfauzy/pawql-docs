# PawQL

PawQL is a runtime-first, type-safe ORM and SQL query builder for TypeScript. Define schemas with JavaScript objects and get inferred query types without a schema language, code generation, or a build step.

It supports PostgreSQL, MySQL/MariaDB, and SQLite through native adapters and runs on Node.js and Bun. Install the `pawql` package and the database driver for your chosen database.

## At a glance

```ts
import { connect } from 'pawql';

const db = await connect({
  users: {
    id: { type: Number, primaryKey: true },
    name: String,
    isActive: { type: Boolean, default: true },
  },
}, 'postgres://user:pass@localhost:5432/mydb');

const users = await db.query('users')
  .where({ isActive: true })
  .orderBy('name', 'ASC')
  .limit(10)
  .execute();
```

See [Adapters](./orm/adapters) for driver installation and dialect differences.
